# 岩田望美｜全案件共通ハブ

岩田望美さん関連の**全案件共通**で使う正本を集約するフォルダです。

## 目的

- 案件ごとに重複しやすい「共通パーツ」を一本化する
- 修正時の更新漏れを防ぐ
- FFSを単なる診断紹介で終わらせず、共通の思想で運用する

## 収録ファイル

| ファイル | 用途 |
|----------|------|
| `00_全案件共通ルール.md` | 案件をまたいで守る運用原則（表記・訴求・保存先） |
| `01_全案件共通マインドセット.md` | 発信・LP・セミナー・個別相談でぶれない思想の土台 |

## 対象案件

- FFSコーチング
- （必要に応じて今後追加）

## 運用ルール

1. **共通変更はこのフォルダを先に更新**する。
2. 案件側に例外がある場合は、案件フォルダの `README.md` に理由を残す。
3. FFSの説明が診断紹介に寄りすぎたら、まず `01_全案件共通マインドセット.md` に立ち返る。
