# オープンチャット用｜占い師クイズ 3本（働き方）

## 九星覚醒カウンセラー｜DAY4前後・働き方の話に入る前後に使う用

> **このクイズの目的**
> - 「占い師＝当てる人」「稼ぐ＝セールスが強い人」という**思い込み**をやさしくほどく
> - 電話・チャット占いや副業の話を、**恐怖ではなく構造**で受け取ってもらう入口にする
> - 九星覚醒の核である **「運は当てるだけでなく、動かすもの」** が、**仕事の形**にもつながると体感してもらう

---

## 使い方の前提

- すべて **3択** にしてあります
- 回答は **「1」「2」「3」だけでOK** にすると参加しやすいです
- 正解発表の前に、1人か2人へ **「それを選んだ理由もよかったら教えてください」** と聞くと盛り上がります
- 正解を責める空気ではなく、**「みんな途中までは合ってる。その中で今日はここを持ち帰ってくださいね」** で着地させるのがコツです
- **開運クイズ5本**・**風水クイズ3本**と併用する場合は、DAY4前の「仕事の形」に触れたい日にこのシリーズを入れると流れが自然です

# 占い師クイズ①｜「当たりました！」だけでは、仕事として足りない理由に近いのは？

## ねらい

占い師の価値は「正答率」だけではない。**解釈と次の一手**まで渡す仕事だ、という視点を入れる。

## 出し方

```
Q.
「当たって喜ばれたのに、
また来てくれません」
と相談されました。

何が足りなかった可能性が高いでしょう？

1. もっと難しい占術を覚えること
2. 鑑定時間を長くすること
3. 相手の状況を言葉にし、次の一歩まで渡すこと
```

## 正解

**3**

## 着地コメント案

「当たる」は大事です。

でも相談者さんが欲しいのは、
**当たった確認だけではなく、次の一歩** です。

「これからどうしたらいいか」まで渡せると、
占いは **読むだけ** ではなく **動かす仕事** になります。

九星覚醒カウンセラーも、
この **解釈＋一手** を届ける仕事です。

---

# 占い師クイズ②｜占いを仕事にしたい。いちばん続けやすい一歩に近いのは？

## ねらい

「完璧になってから」「いきなり独立」という極端を避け、**今の生活の中で続く形**から始める視点を入れる。

## 出し方

```
Q.
「占いを仕事にしたいです。
最初の一歩は何ですか？」
と聞かれました。

いちばん続けやすいのはどれでしょう？

1. いきなり独立して占い一本にする
2. 今の生活を続けながら、学びと実践を少しずつ始める
3. 完璧に覚えてから始める
```

## 正解

**2**

## 着地コメント案

①も③も気持ちはわかります。

でも、
**いきなり全部かける**
**完璧を待つ**
この2つは止まりやすいです。

大事なのは、
**今の生活の中で続けられる形から始めること**。

その積み重ねが、
仕事につながっていきます。

DAY4では、それが
**電話・チャット占い** にどうつながるかもお話しします。

---

# 占い師クイズ③｜電話・チャット占いの「審査」で見られやすいのは？

## ねらい

審査＝恐怖の関門、ではなく、**相手の話を届けられるか**という構造で伝える。DAY4への橋渡し。

## 出し方

```
Q.
電話・チャット占いに応募したいけれど、
「審査がある」と聞いて
不安になっている方がいます。

審査で見られやすいのはどれでしょう？

1. 相手の話を受け止め、役立つ形で届けられるか
2. 一度で未来を全部当てられるか
3. 派手で目立つ話し方ができるか
```

## 正解

**1**

## 着地コメント案

②③を選ぶ方も多いです。

でも審査で見られやすいのは、
**当てる力だけ** ではありません。

**聞く力**
**気持ちを言葉にする力**
**役立つ形で届ける力**

ここが大切です。

九星覚醒で育てる力は、
そのまま仕事にもつながっています。

審査は怖い関門ではなく、
**自分に合う働き方か確かめる入口** です。

## 講師向けメモ

### 盛り上げ方

- 「占い師になりたい／なってみたい方、いますか？」と先に聞く
- 「②にした方、今のお仕事と両立、大変ですよね」と共感を拾う
- 正解発表の前に「③が多いですね。理由、教えてください」と間をつくる

### 教育として外さないポイント

- 働き方を **煽らない**（「今すぐ辞めて独立」系は避ける）
- 毎回の着地は、次のどれかに必ずつなぐ
  - 占い師の仕事＝**解釈と次の一手**まで渡すこと
  - 最初の一歩は **今の生活の中で続く形** から
  - 電話・チャット占いは **恐怖の関門** ではなく **構造の話**（DAY4へ）
