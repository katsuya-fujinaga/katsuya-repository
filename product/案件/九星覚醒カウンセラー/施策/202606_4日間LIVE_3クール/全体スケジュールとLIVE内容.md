# 本編｜4日間LIVE（各60〜90分・本田有紀華）

## DAY1｜6/22（月）20:00〜

**テーマ**：なぜこのコンテンツが必要か  
**役割**：世界観／運の再定義／問題提起／4日間の地図／動機づけ

| No | ブロック | 内容 | 時間目安 |
|---|---|---|---|
| ① | オープニング・フック・ワーク | 「運＝コントロールできないもの」は**半分ハズレ**。60秒ワーク（悩み1つ→方位/待ち/努力で詰まり→**未来／感情／一手**の欠け） | 0:00〜12:00 |
| ② | 需要・チャンス | 開運・自己理解の需要／電チャ需要／「当てるだけ」から抜けた**動かす側**のポジション | 12:00〜22:00 |
| ③ | 運の正体 | 運＝**確率×行動×解釈**／当たりやすい場所に立つ力。「運が悪い」→リソース分散の見方 | 22:00〜35:00 |
| ④ | 才能と運 | 才能10年 vs 運10年 → **運を育てる習慣**（待つ vs 動かす） | 35:00〜42:00 |
| ⑤ | 四つのつまずき | 吉方位だけ／一般論／読んで終わり／感情レイヤ不足 → 九星覚醒の立ち位置 | 42:00〜50:00 |
| ⑥ | 九星×タロ | **未来を読む（九星）** vs **いまの感情（タロ）**／合体必須ではない | 50:00〜56:00 |
| ⑦ | デモ | 同じ相談を九星寄り／タロ寄り／両方で見せる（90秒程度） | 56:00〜66:00 |
| ⑧ | 4日間の地図 | 三つの力・DAY2〜4予告・やさしく売れる占い師との差別化 | 66:00〜76:00 |
| ⑨ | ひとりでは／いま動く理由 | 型の必要性・恐怖ではない動機 | 76:00〜84:00 |
| ⑩ | 締め・課題 | 復唱・課題（例：本命星を調べる） | 84:00〜 |

**DAY1で伝える一言**：開運の人＝運が強い人ではない。**読んで終わらせず、育てる人**。

**台本正本**：[4日間LIVE_DAY1_シナリオ](../../シナリオ/4日間LIVE_DAY1_シナリオ.md)
