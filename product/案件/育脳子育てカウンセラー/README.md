# 育脳子育てカウンセラー

## 📌 概要

- クライアント：永瀬まみ（日本ママアカデミー協会）
- 目的：ママ向け「点ではなく線で育脳する」→ 育脳子育てカウンセラー® 養成
- **フォルダ用途**：旧プロモ一式の保管（lp00/lp01・5ちゃれ・過去LIVE・過去メール等）
- 現行の「おうち育脳」プロモは **`../おうち育脳カウンセラー/`** を正とする
