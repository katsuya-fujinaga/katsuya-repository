# タロットクイズ 5本｜ウォーミングアップ用

## 九星覚醒カウンセラー｜セミナーオープニング

> **立ち位置** … 正解合戦ではなく、**「あるある」でふふっと笑って、場の空気を温める** くらいでOK  
> **Q** … 出題・チャット投稿用（そのまま使える）  
> **A** … スライド1枚。笑いのあとに、ひとことだけ「そういうこともあるんだ」で締める

---

## 使い方の前提

- すべて **3択**。番号だけで答えてもらう
- **正解の番号はバラバラ**（①②③①② — 全部同じにならないよう調整済み）
- 口頭では **「正解は〇。でも他の番号、すごくわかります（笑）」** が鉄板
- 深い解説はしない。1問 **2〜3分** で次へ
- 5問全部だと長いので、オープニングでは **2〜3問** ピックアップでOK

### 正解一覧（講師用）

| 問 | 正解 |
|---|---|
| ① | **1** |
| ② | **2** |
| ③ | **3** |
| ④ | **1** |
| ⑤ | **2** |

---

## 進行イメージ

- **本編の前** … ①＋②、または ①＋③＋④ など、2〜3問で十分
- **DAY3の前** … ②③④⑤ から選ぶと、タロの話につながりやすい

### 共通の振り方（口頭）

```
さて、ウォーミングアップに
タロットあるあるクイズ、いきます。

正解は1つじゃないかもしれません。
直感で、番号だけ送ってくださいね。
```

# タロットクイズ①｜「死神」が出た瞬間、相談者さんの顔が止まりました

## ねらい（講師だけ）

怖いカード＝失敗じゃない、を**笑いながら**ほのめかす。

## 出し方

```
Q.
鑑定で、いちばん出たがりのカード
「死神」が出ました。

相談者さんの顔が、
いっしゅんフリーズしました。

あなたなら、次のどれ？

1. 「こわいですよね。
   どこがいちばんこわいですか？」と聞く

2. 急にテンション上げて
   「いい意味もありますよ〜！」だけ言う

3. 知らんぷりでスルー
   「では、次のカードいきますね」
```

## 正解

**1**

## A（スライド1枚）

**タイトル**

正解は ① です！ ……でも②、わかります（笑）

**本文**

- ②の「いい意味もありますよ〜」、出たことある方、挙手多いです
- 「死神＝今日で人生終了」ではないんですよね、たいてい
- まず「どこがこわい？」——ここ、ちょっと笑えるけど大事
- そのあと「いまはここ。こう動くと楽になることもあるよ」
- 怖いカード＝鑑定失敗？ いえいえ。**心が動いた合図** です

# タロットクイズ②｜「で、結局、何すればいいんですか？」

## ねらい（講師だけ）

読んで終わりにしない、を**あるある**で入れる。

## 出し方

```
Q.
タロットからのメッセージを伝えたところ、
相談者さんが真顔で言いました。

「わかりました。で、結局、何すればいいんですか？」

あなたなら、次のどれ？

1. 「では、もう3枚引きますね」

2. 「これからきそうなこと、
   一緒に考えましょうか？」

3. さっきのカードの意味を、
   もう一度、くわしく、長く
```

## 正解

**2**

## A（スライド1枚）

**タイトル**

正解は ② です！ ……でも①③、わかります（笑）

**本文**

- ①③は「情報をふやす」。悪くない。でも胃もたれしやすい
- 相手が欲しいのは、たいてい **ToDoリスト1行分**
- タロは未来を決めつける道具じゃなく、**いまの気持ちを出す道具**
- 気持ちが見えたら、「これからきそうなこと」を**一緒に考える**——②のイメージ
- 読んで終わりじゃなく、**動きの入口**。ここだけ覚えて帰ってください

# タロットクイズ③｜カードを見せたら、沈黙が3秒続きました

## ねらい（講師だけ）

沈黙＝失敗じゃない、を**気まずさネタ**でほどく。

## 出し方

```
Q.
カードをそっと見せたら、
相談者さんが黙りました。

Zoomの空気が、
「なんか言って……」ってなりました。

あなたなら、次のどれ？

1. カードの意味を、
   早口で、たくさん、話す

2. 「今日の晩ごはん、何にします？」
   と雑談に逃げる

3. 「いま、頭に浮かんでること、
   ひとことだけでもお伝えしていいですか」
```

## 正解

**3**

## A（スライド1枚）

**タイトル**

正解は ③ です！ ……でも②、味方です（笑）

**本文**

- 黙った＝嫌われた、とは限りません（ほっと一息）
- 言葉にならない気持ちが、いま出てきているだけ、ことも多い
- まず「お伝えしていいですか？」の一言。それだけで十分
- ①の早口説明、②の晩ごはん雑談——やった人、共感の目が合います
- 焦らなくて大丈夫。**間も、鑑定の一部** です

# タロットクイズ④｜「当たってないですよね？」と言われました

## ねらい（講師だけ）

当たり外れの勝負にしない。**どこが刺さったか／刺さらなかったか** を聞く。

## 出し方

```
Q.
メッセージを伝えたら、
相談者さんが困った顔で言いました。

「……当たってないですよね？」

あなたなら、次のどれ？

1. 「どの部分がしっくりこなくて、
   どの部分は当たってる感じですか？」と聞く

2. 「いえ、ちゃんと当たってますよ」
   と強く言う

3. 「では、もう一度別の並びで引き直しますね」
```

## 正解

**1**

## A（スライド1枚）

**タイトル**

正解は ① です！ ……でも②、出たことあります（笑）

**本文**

- ②は気持ちはわかる。でも「当たってます」勝負になりやすい
- ③の引き直しも、たまにはアリ。でも不安が残ることも
- **当たり外れより、「どこが自分の話か」** を一緒に探す
- しっくりこない所＝大事なヒント、になることも多いです
- タロは、相手の**いま**に重ねると刺さりやすい——④のポイント

# タロットクイズ⑤｜シャッフルする前、いちばん先にすることは？

## ねらい（講師だけ）

いきなり引かない。**何を知りたいか** を先に聞くクセを、軽く入れる。

## 出し方

```
Q.
鑑定が始まりました。
カードはまだ引いていません。

いちばん先にすることは、どれ？

1. テンション上げて、
   すぐシャッフルして引く

2. 「今日、いちばん知りたいことは
   何ですか？」と聞いてから引く

3. 「吉方位はこちらです」と
   先にアドバイスする
```

## 正解

**2**

## A（スライド1枚）

**タイトル**

正解は ② です！ ……でも①、わかります（笑）

**本文**

- ①の「とりあえず引く」、緊張すると出がちです
- ③は九星寄り。悪くないけど、**いまの相談** が見えにくいことも
- 先に「何が知りたいか」——シンプルだけど効く一手
- 質問がはっきりすると、引いたあとの話も入りやすい
- ウォーミングアップの結論：**焦らず、相手のいまから** でOKです

## 講師向けメモ

### ウォーミングアップとしてのコツ

| やること | やらないこと |
|---|---|
| 正解番号は問ごとに違う（①②③①②） | 5問とも同じ番号 |
| 「①多い！②③も英雄（笑）」など変える | 長い解説・用語の説明 |
| 1問2〜3分。オープニングは2〜3問で十分 | 5問全部を本編前にやる |

### 5問の役割（かぶせない）

| 問 | 正解 | ネタの軸 |
|---|---|---|
| ① | **1** | 怖いカード・死神フリーズ |
| ② | **2** | で、何すればいい？ |
| ③ | **3** | Zoom沈黙 |
| ④ | **1** | 当たってないですよね？ |
| ⑤ | **2** | 引く前に何を聞く？ |
