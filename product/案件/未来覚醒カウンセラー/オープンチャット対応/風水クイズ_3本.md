# オープンチャット用｜風水クイズ 3本

## 九星覚醒カウンセラー｜カウントダウン・DAY1前後に使う用

> **このクイズの目的**
> - 「風水＝部屋を整えれば全部うまくいく」という**思い込み**をやさしくほどく
> - 風水・方位・環境の力は**否定せず**、九星覚醒の核である **「運は当てるだけでなく、動かすもの」** に接続する
> - 参加者が**コメントしやすい空気**をつくり、DAY1本編の理解を深める

---

## 使い方の前提

- すべて **3択** にしてあります
- 回答は **「1」「2」「3」だけでOK** にすると参加しやすいです
- 正解発表の前に、1人か2人へ **「それを選んだ理由もよかったら教えてください」** と聞くと盛り上がります
- 正解を責める空気ではなく、**「みんな途中までは合ってる。その中で今日はここを持ち帰ってくださいね」** で着地させるのがコツです
- **開運クイズ5本**と併用する場合は、日替わりで交互に出すか、DAY1前の「環境・空間」に触れたい日に風水クイズを入れると流れが自然です

---

## 進行イメージ

### クイズを入れるおすすめ箇所

- 風水クイズ①：「単なる風水・方位学ではない」に触れる前後（環境の話の導入）
- 風水クイズ②：リソース分散・「がんばりすぎ」の話の前後
- 風水クイズ③：九星とタロットの役割分担・「その人の話」に入る前

### 共通の振り方

```
ここで、ちょっとだけ風水クイズです。
気軽に番号だけで答えてくださいね。
```

# 風水クイズ①｜部屋を整えたのに、なぜか動かない。いちばん足りないのは？

## ねらい

「吉方位・ラッキーカラー・家具の向き」だけでは現実が動きにくい、という感覚を入れる。

## 出し方

```
Q.
友人が、風水本どおりに
寝室の向きや色を変えました。

でも、
「部屋はきれいなのに、仕事が進まない」
と弱気になっています。

いちばん足りないのは、どれだと思いますか？

1. もっと高い開運グッズを置くこと
2. もう一度別の方位本を当てはめること
3. その時期の自分の流れと、いまできる小さな一手をセットで見ること
```

## 正解

**3**

## 着地コメント案

部屋を整えること自体は、悪いことではありません。

むしろ、**心が落ち着く・動きやすくなる**ことはあるんです。

でも、環境だけ整えて、
**「で、いま自分は何をするの？」** が見えないと、
現実は動きにくいままです。

九星覚醒では、風水や方位は**材料のひとつ**。

その人の本質の筋、その時期の流れ、
そしていまの生活でできる**小さな一手**までセットにすると、
「動いた感じ」がつかみやすくなります。

# 風水クイズ②｜「この部屋の風水が悪いから」と言われたら、まず近いのは？

## ねらい

環境を**責め合いの道具**にしない。相談の入口は「その人のいま」にある、という視点を入れる。

## 出し方

```
Q.
相談者さんが、
「夫がうちの部屋の風水が悪いから、
　うまくいかないんです」
と言ってきました。

カウンセラーとして、
まず近いのはどれですか？

1. 部屋の間取り図を見て、悪い方位を特定する
2. 夫の言い方が間違っていると指摘する
3. いま、あなたがいちばんつらいと感じているのはどこですか？と聞く
```

## 正解

**3**

## 着地コメント案

風水の話が出てきたとき、
いきなり「間取りの正解」を探しにいくと、
相手の**いまの気持ち**が置き去りになりやすいんです。

大事なのは、部屋が悪いかどうかを争うことではなく、
**その人が今、どこで止まっているか**を見ること。

つらさの正体が、環境なのか。
人間関係なのか。
自分の中の言葉にならない気持ちなのか。

そこが見えると、九星から入るのか、タロットから入るのか、
風水の話をどう活かすのかも、選びやすくなります。

# 風水クイズ③｜SNSで「これを置けば開運」と流行ったとき、占い師として大事なのは？

## ねらい

一般論の風水情報と、「その人の話」に変える鑑定の違いを伝える。

## 出し方

```
Q.
SNSで
「玄関にこれを置けば金運アップ」
という情報が流行っています。

相談者さんが、
「私も置いた方がいいですか？」
と聞いてきました。

占い師として、いちばん大事なのはどれですか？

1. 流行っているなら、みんな置いているから勧める
2. 置かないと運が下がると伝えて、行動を急がせる
3. あなたの場合、いまいちばん気になっているお金のことは何ですか？と聞く
```

## 正解

**3**

## 着地コメント案

流行の開運情報は、**入り口としては便利**です。

でも、それだけで終わると、
相手の人生には刺さりにくいんですね。

相手が欲しいのは、
「みんながやっているから正しい」という説明だけではなく、
**「私の話としてわかってもらえた」** という感覚です。

風水の知識は**材料**。

そこに **相手のいま** を重ねた瞬間、
アドバイスが「当てる」から **「動かす」** に変わっていきます。

---

## 講師向けメモ

### 盛り上げ方

- 「風水に詳しくなくて大丈夫です。直感で1つ選んでくださいね」と先に言う
- 「部屋の話、わかります」と共感のコメントが来たら、ひと言拾う
- 正解発表の前に「①が多いですね」「③にした方、理由教えてください」と間をつくる

### 教育として外さないポイント

- 風水を**否定しない**（「ダメです」ではなく「それだけだと足りることがある」）
- 毎回の着地は、次のどれかに必ずつなぐ
  - 環境は材料。運を動かすには**その人のいま**と**一手**が必要
  - 部屋を責めるより、**どこで止まっているか**を見る
  - 一般論で終わらせず、**相手の話**に変える

### 開運クイズ5本との使い分け

| シリーズ | ねらい |
|---|---|
| 開運クイズ | 運の定義・読むだけで終わらない・九星×タロの入口 |
| 風水クイズ | 環境・空間・流行情報への**誤解のほどき** |

### トーン

- 「間違いです」ではなく **「九星覚醒で大事にしているのはここです」**
- 参加者を試す空気ではなく、**一緒に視点を育てる空気** にする
