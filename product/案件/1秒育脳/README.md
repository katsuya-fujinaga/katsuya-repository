## 📌 概要

- クライアント：永瀬まみ（日本ママアカデミー協会）
- 目的：0〜6歳の土台をつくる「1秒育脳®」の実践を、保育・教育・支援に関わる方へ届ける
- 現状：入口LP「1秒育脳®のはじめかた」→ 無料4日間LIVEレッスン（2026年6月22日スタート・1日おき）

**親ブランドとの関係**：育脳子育てカウンセラー® 傘下のメソッド・入口企画。ママ向け「育脳子育てカウンセラー」導線（`../育脳子育てカウンセラー/`）とはターゲット・訴求を分ける。
