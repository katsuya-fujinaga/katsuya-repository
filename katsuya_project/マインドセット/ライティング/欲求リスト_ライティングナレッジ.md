# 欲求リスト｜ライティングナレッジ

メール・LP・レター・台本・セールス文を書くとき、**読み手の欲求**から言葉を選ぶための案件横断ナレッジ。

出典は、いとうさん『【保存版】欲求レポート』（全26ページ）。正本PDFは [【保存版】欲求レポート](https://drive.google.com/file/d/1fw8wjvqixY0A2wJVF9NR5DjYdktK4WPH/view?usp=sharing)。ここは執筆用に要点を再構成したもので、原文の全文転載ではない。

階層は `katsuya_project ＞ マインドセット ＞ ライティング`。

## 執筆の前提

- 自分の欲求と、相手の欲求は違う。書き手の欲しい未来を、相手の欲しい未来だと思わない。
- 多くの人は、親・家族・周囲が欲しがるものを、自分の欲求だと思っている。
- 手に入れたあとに「これじゃない」と感じるのは、表面のモノと、奥の欲求がずれているとき。
- 痛みを避ける力は、快楽を求める力より強い、という前提で書く。恐怖で煽るためではなく、**今つらいこと**を先に言葉にするため。
- 下の欲求（生きる、安心、居場所）が満たされていない人に、自己実現から入らない。
- 一つの原稿で全部の欲求を並べない。今の読者に一番近い欲求を、一つに絞る。
- このリストは、相手を動かすための操作表ではない。訴求のズレを減らし、相手が「自分のことだ」と感じる言葉を選ぶために使う。

## 書く前の3問

1. この人は今、何が足りなくて止まっているか（痛み・欠乏）。
2. それは「得たい」か、「失いたくない・支配されたくない」か。
3. 書き手自身の強い欲求（認められたい、売れたら、支配したい）を、本文に出していないか。

件名は理由の説明にしない。読者のずれや痛みが、開く前に見える一文にする。

## 3つのS

人の行動の底にある本能。

| 欲求 | 中身 |
|------|------|
| サバイバル | 生き残りたい。生命、食料、安全 |
| セックス | 遺伝子を残したい。魅力、結びつき |
| ステータス | 他者より優れたい、選ばれたい、地位が欲しい |

コピーの土台がこのどれかに触れているかを見る。触れていなければ、上の理念だけになって届きにくい。

## 快楽原則

- 痛みを避けたい。
- 快楽を得たい。
- 痛み回避のほうが優先されやすい。
- 「問題をほどきたい」は、「理想を追い続けたい」より、しっくり来る人が多い。

使い方は、痛みを大きくすることではない。すでに感じている痛みに名前をつけ、そのあとでほどける側を見せる。

## マズローの8段階

下から満たされて、次が出る、という見立て。認知・審美・自己超越がピンとこない相手には、従来の5段階（生理・安全・親和・承認・自己実現）でよい。

| 段階 | 欲求 |
|------|------|
| 1 生理 | 呼吸、水、食事、排泄、睡眠、生殖、生命維持 |
| 2 安全 | 個室、セキュリティ、貯金、安定した仕事と収入 |
| 3 親和（所属） | 家族・友人・恋人、愛情、グループ、居場所 |
| 4 承認（自我） | 自尊心、尊敬されたい、違いを出したい |
| 5 認知 | 知りたい、理解したい、探求したい、成長したい |
| 6 審美 | 調和、秩序、美 |
| 7 自己実現 | 理想、道徳、創造、問題を解く、才能を発揮する |
| 8 自己超越 | コミュニティ、世界、隣人 |

生理と安全は欠乏欲求。ここが揺れている人には、使命や自己実現から書き始めない。

## 6つのモチベーション

権力・親和・達成の「得たい」と、それぞれの「失いたくない」を掛けたもの。人によって強弱がある。

| | 獲得 | 防衛 |
|--|------|------|
| 権力 | 支配したい。言うことを聴かせたい | 支配されたくない。自由でいたい。頭を下げたくない |
| 親和 | 好かれたい。愛されたい。チヤホヤされたい | 嫌われたくない。仲間外れ、無視されたくない |
| 達成 | 達成したい。成功したい。達成感が欲しい | 失敗したくない。恥をかきたくない。プライドを守りたい |

原稿では、獲得側だけを書かない。この読者が手放したくない側（失敗、支配、孤立）を一文入れる。

## 6ヒューマンニーズ

| ニーズ | 中身 |
|--------|------|
| 安定性 | 安定したい、安心が欲しい |
| 不安定性 | 刺激や変化が欲しい |
| 重要感 | 価値ある特別な存在でいたい |
| 愛と繋がり | 人と繋がり、愛されたい |
| 成長 | 今より成長したい |
| 貢献 | 他者のために役立ちたい |

安定と変化は反対に見えるが、両方持つ人がいる。どちらが今強いかを、案件の読者に合わせて一つ選ぶ。

## ライフフォース8

広告の前線で繰り返し反応があった、反応せざるを得ない要素。

1. 生き残り、人生を楽しみ、長生きしたい
2. 食べ物、飲み物を味わいたい
3. 恐怖、痛み、危険を免れたい
4. 性的に交わりたい
5. 快適に暮らしたい
6. 他人に勝り、世の中に遅れをとりたくない
7. 愛する人を守り、気遣いたい
8. 社会的に認められたい

## セカンドフォース9

ライフフォース8の次に効く、より高次の要素。訴求力は8より落ちる。

1. 情報が欲しい
2. 好奇心を満たしたい
3. 身体や環境を清潔にしたい
4. 能率良くありたい
5. 便利であってほしい
6. 信頼性、質の良さがほしい
7. 美しさと流行を表現したい
8. 節約し、利益を上げたい
9. 掘り出し物を見つけたい

情報や便利さだけで書くと弱くなる。その下に、生き残り・痛み回避・承認のどれかが要る。

## 原稿での使い方

1. 読者を一人決める。
2. 上のリストから、今その人に一番近い欲求を一つ選ぶ。防衛側があるなら、それも一文足す。
3. 件名は、その欲求のずれが見える具体にする。「なぜ無料か」のようなこちらの理由は件名にしない。
4. 本文は、その欲求がすでに起きている場面から入る。
5. 商品は、その欲求がほどける鍵として最後に置く。
6. 書き終えたら、書き手の欲求（売りたい、認められたい、支配したい）が主語になっていないか読む。

講座ビジネスでは、よく近いのは次の組み合わせ。

- 安全（収入・将来）＋失敗したくない
- 親和（居場所・孤独）＋嫌われたくない
- 承認（これまでを見てほしい）＋重要感
- 養育・貢献（誰かの役に立ちたい）＋愛する人を守りたい
- 認知（知りたい、形にしたい）は、その下に痛みがあるときだけ効く
