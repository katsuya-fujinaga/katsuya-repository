# ひとびじ（藤永勝也｜個人プロジェクト）

Katsuya Fujinaga 個人ブランド **ひとびじLAB** まわりの原稿・ナレッジを、このフォルダに集約しています。

**Git 上の正本はこのフォルダ（`katsuya_project/ひとびじ/`）**です。同じ **Katsuya プロジェクト**の **型**（`マインドセット/`）はひとつ上の階層に並びます。Obsidian ボルトでは **`obsidian/ひとびじ`** がここへのシンボリックリンクになります。

| サブフォルダ | 内容 |
|--------------|------|
| **`ブランド設計/`** | ペルソナ、コンセプト検証、ブランドの芯。 |
| **`プロフィール/`** | 藤永勝也のプロフィール、Xプロフィール、経験値カード文言。 |
| **`運用/`** | X運用など、媒体横断の運用設計メモ。 |
| **`メール/`** | メール関連の素材置き場。現状は **`メール/ハウスメール/`** に、メルマガ「ひとりビジネスの教科書」原稿を格納。 |
| **`SNS/`** | SNS 発信用の素材置き場。現状は **`SNS/X/戦略/`** と **`SNS/X/投稿ストック/`** に分類。運用設計の正本は **`運用/X運用_濃いフォロワー設計_非集客フェーズ.md`**。 |

メール運用のインデックス（全案件の形式・ボルト・`product/` の対応）は **`../メールライティング/README.md`**。  
ひとびじ固有のハウスメール運用メモは **`メール/ハウスメール/README.md`** を見る。

Cursor のブランド正本は引き続き **`.cursor/rules/hitobizi-lab.mdc`**。ワークスペース上のコピー・たたき台は、内容に応じて **`ブランド設計/`**・**`プロフィール/`**・**`運用/`** を編集してください。
