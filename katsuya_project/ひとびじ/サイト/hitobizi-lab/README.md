# 50代からのひとりビジネスのはじめ方｜WordPressテーマ

[katsuyafujinaga.com](https://katsuyafujinaga.com/) 向けの公式サイトテーマです。  
**ブログは WordPress の投稿機能を使い、見た目はオリジナル**にしています。

テーマ Version: **1.3.0**（公式サイト型ホーム＋ブログ維持）

## 表記ルール（統一）

| 項目 | 文言 |
|------|------|
| サイトのタイトル | `50代からのひとりビジネスのはじめ方` |
| キャッチフレーズ | `藤永勝也｜ひとびじLAB` |
| ヘッダー／フッター表記 | `ひとびじLAB` ＋ `藤永勝也｜50代からのひとりビジネスのはじめ方` |
| ブランド略称 | `ひとびじLAB`（ひらがな＋LAB） |
| 「ひとり」 | 漢字の「一人」は使わない |

WordPress の **設定 → 一般** にも、上のサイトタイトル／キャッチフレーズを入れてください。  
（ヘッダー表示はブランド固定。検索タイトル等は `blogname` / `blogdescription` を使います）

デザインの色味は、淡い水色・余白多め・やさしいトーンのままです。  
ホームは田中祐一公式サイト型のスキャンしやすい構成（STORY／METHOD／入り口カード／FREE／記事）に寄せています。

## ホーム構成（1.3.0）

1. **Hero** … テキスト主役＋バナー画像
2. **Proof** … やわらかい証明ストリップ（飲食店13年／講座伴走／50代再起動）
3. **For You** … こんな人向け
4. **STORY** … どんな人か＋なぜ書くか
5. **METHOD** … 届け方の5ステップ
6. **SERVICE** … 入り口3枚（記事／プロフィール／実績）
7. **ACTIVITY** … お知らせカテゴリに投稿があるときだけ表示
8. **Articles / Latest** … カテゴリ入口＋最新記事（ブログの主役）
9. **FREE** … まずは無料で読む（当面は記事一覧。メルマガURLは `front-page.php` の `$free_url` を差し替え）
10. **Profile** … 短い紹介＋詳細導線

## サーバーへの上げ方（最短）

1. このフォルダ `hitobizi-lab` を zip にする  
   （中に `style.css` が直下にある状態で zip。二重フォルダにしない）
2. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
3. `hitobizi-lab` を有効化（すでに有効ならファイル上書きでも可）
4. 下の「初回セットアップ」を実施（初回のみ）

FTP で上げる場合は、次へアップロードします。

```
wp-content/themes/hitobizi-lab/
```

## 初回セットアップ（管理画面）

### 0. サイト名・キャッチフレーズ（統一）

**設定 → 一般**

- サイトのタイトル：`50代からのひとりビジネスのはじめ方`
- キャッチフレーズ：`藤永勝也｜ひとびじLAB`

テーマ有効化時、初期のままなら自動でこの文言に寄せます。すでに独自設定がある場合は上書きしません。

### 1. 固定ページを作る

| タイトル | スラッグ | テンプレート |
|----------|----------|--------------|
| ホーム | `home`（任意） | 指定なしでOK（フロントに設定） |
| プロフィール | `profile` | **プロフィール** |
| 実績 | `results` | **実績** |
| 記事 | `articles` | 指定なし（投稿ページに設定） |

### 2. 表示設定

**設定 → 表示設定**

- ホームページ：`ホーム`
- 投稿ページ：`記事`

### 3. カテゴリ

テーマ有効化時に、次のカテゴリを自動作成します。

- 再起と働き方
- プロデュース論
- マーケティング
- コンテンツ販売
- 仕事術・思考法
- お知らせ

足りなければ **投稿 → カテゴリー** で追加してください。

### 4. メニュー

**外観 → メニュー**

例：

1. ホーム
2. プロフィール
3. 実績
4. 記事
   - 再起と働き方
   - プロデュース論
   - マーケティング
   - コンテンツ販売
   - 仕事術・思考法
   - お知らせ

表示位置：**メインメニュー**（任意でフッターも）

メニュー未設定でも、テーマ側のフォールバックメニューが出ます。

### 5. パーマリンク

**設定 → パーマリンク** → 「投稿名」推奨 → 保存

## 記事の書き方（ブログ維持）

1. **投稿 → 新規追加**
2. カテゴリを1つ選ぶ（上の6つから）
3. 公開

これだけで、ホームの最新記事・記事一覧・カテゴリページに反映されます。  
お知らせカテゴリに投稿すると、ホームの ACTIVITY にも出ます。

## ローカルで見た目だけ確認したい場合

このテーマは PHP なので、**WordPress 本体がないとブラウザ単体では動きません**。  
確認手段は次のいずれかです。

- 本番 WordPress にアップロードして確認（いちばん確実）
- Local / MAMP などでローカル WordPress を立ててテーマを入れる
- まずは本番の下層（例：`/preview/`）に WordPress を仮置きして確認

## 注意

- いまの公開サイトが WordPress なら、テーマ差し替えで見た目が変わります（投稿データは残ります）
- 既存テーマのウィジェットやページビルダー設定は引き継がれません
- メルマガ登録URLが決まったら、`front-page.php` 上部の `$free_url` / `$free_label` を差し替えてください

## 次にやるとよいこと

1. テーマをアップロードして有効化（または上書き）
2. 固定ページ4つ＋表示設定（未設定なら）
3. メニュー作成
4. テスト投稿を1本公開して表示確認
5. FREE帯のURLを本番用に差し替え
