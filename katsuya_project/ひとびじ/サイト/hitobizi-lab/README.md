# 50代からのひとりビジネスのはじめ方｜WordPressテーマ

[katsuyafujinaga.com](https://katsuyafujinaga.com/) 向けの公式サイトテーマです。  
**ブログは WordPress の投稿機能を使い、見た目はオリジナル**にしています。

## 表記ルール（統一）

| 項目 | 文言 |
|------|------|
| サイトのタイトル | `50代からのひとりビジネスのはじめ方` |
| キャッチフレーズ | `藤永勝也｜ひとびじLAB` |
| ブランド略称 | `ひとびじLAB`（ひらがな＋LAB） |
| 「ひとり」 | 漢字の「一人」は使わない |

WordPress の **設定 → 一般** にも、上と同じ文言を入れてください。  
ヘッダー／フッターは `blogname` / `blogdescription` を表示します。

デザインの方向性は、淡い水色・余白多め・丸みのあるボタン・やさしいLP調（参考：[星読み無料講座LP](https://noplanetnolife.com/l/geo/hoshitoikiru_g)）です。  
トップページは長い読み物型（目次・共感・理由・届け方・学べること・記事・プロフィール）に作り込んでいます。

## サイト構成（おすすめ案どおり）

| メニュー | 種類 | 備考 |
|----------|------|------|
| ホーム | 固定ページ（フロント） | `front-page.php` |
| プロフィール | 固定ページ | テンプレート「プロフィール」 |
| 実績 | 固定ページ | テンプレート「実績」（信頼導線用に独立） |
| 記事 | 投稿ページ | ブログ一覧 |
| └ 再起と働き方 | カテゴリ | `saiki-hatarakikata` |
| └ プロデュース論 | カテゴリ | `produce` |
| └ マーケティング | カテゴリ | `marketing` |
| └ コンテンツ販売 | カテゴリ | `content-sales` |
| └ 仕事術・思考法 | カテゴリ | `workstyle-thinking` |
| └ お知らせ | カテゴリ | `news` |

※「プロジェクト実績」は記事カテゴリではなく、**固定ページ「実績」**にしています。埋もれにくく、信頼形成の導線として強いためです。

## サーバーへの上げ方（最短）

1. このフォルダ `hitobizi-lab` を zip にする  
   （中に `style.css` が直下にある状態で zip。二重フォルダにしない）
2. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
3. `hitobizi-lab` を有効化
4. 下の「初回セットアップ」を実施

FTP で上げる場合は、次へアップロードします。

```
wp-content/themes/hitobizi-lab/
```

## 初回セットアップ（管理画面）

### 0. サイト名・キャッチフレーズ（統一）

**設定 → 一般**

- サイトのタイトル：`50代からのひとりビジネスのはじめ方`
- キャッチフレーズ：`藤永勝也｜ひとびじLAB`

テーマ有効化時、初期のままなら自動でこの文言に寄せます。すでに独自設定がある場合は上書きしません。

### 1. 固定ページを作る

| タイトル | スラッグ | テンプレート |
|----------|----------|--------------|
| ホーム | `home`（任意） | 指定なしでOK（フロントに設定） |
| プロフィール | `profile` | **プロフィール** |
| 実績 | `results` | **実績** |
| 記事 | `articles` | 指定なし（投稿ページに設定） |

### 2. 表示設定

**設定 → 表示設定**

- ホームページ：`ホーム`
- 投稿ページ：`記事`

### 3. カテゴリ

テーマ有効化時に、次のカテゴリを自動作成します。

- 再起と働き方
- プロデュース論
- マーケティング
- コンテンツ販売
- 仕事術・思考法
- お知らせ

足りなければ **投稿 → カテゴリー** で追加してください。

### 4. メニュー

**外観 → メニュー**

例：

1. ホーム
2. プロフィール
3. 実績
4. 記事
   - 再起と働き方
   - プロデュース論
   - マーケティング
   - コンテンツ販売
   - 仕事術・思考法
   - お知らせ

表示位置：**メインメニュー**（任意でフッターも）

メニュー未設定でも、テーマ側のフォールバックメニューが出ます。

### 5. パーマリンク

**設定 → パーマリンク** → 「投稿名」推奨 → 保存

## 記事の書き方

1. **投稿 → 新規追加**
2. カテゴリを1つ選ぶ（上の6つから）
3. 公開

これだけで、ホームの最新記事・記事一覧・カテゴリページに反映されます。

## ローカルで見た目だけ確認したい場合

このテーマは PHP なので、**WordPress 本体がないとブラウザ単体では動きません**。  
確認手段は次のいずれかです。

- 本番 WordPress にアップロードして確認（いちばん確実）
- Local / MAMP などでローカル WordPress を立ててテーマを入れる
- まずは本番の下層（例：`/preview/`）に WordPress を仮置きして確認

## 注意

- いまの公開サイトが WordPress なら、テーマ差し替えで見た目が変わります（投稿データは残ります）
- 既存テーマのウィジェットやページビルダー設定は引き継がれません
- メルマガ登録URLが決まったら、`front-page.php` の CTA を差し替えてください
