## このフォルダ用の要約

| 項目 | 内容 |
|------|------|
| **ファイル名** | 通番つきの完成稿を正とする。詳細な命名規則は **`.cursor/rules/email-writing-format.mdc`** を参照。 |
| **原稿冒頭メタ** | 5行メタの型・区切り線・件名欄の扱いなど、**形式の詳細は共通ルールを正**とする。 |
| **連載まわり** | 「前回」「次回」「続き」「1話読切」など、連載・話数のくだりは**書かない**。毎回完結。 |
| **次回予告** | **書かない** |
| **呼称** | **お客さま**に統一（「お客さん」は使わない） |

## ヘッドライン設計（全体ナレッジ）

- 1行目に「いちばん大事なこと」を置く（結論・緊張・違和感のどれか）
- 2〜3行目で理由や背景を**間接的に**示す（「なぜなら」をにおわせる）
- 日記の説明ではなく、情景や比喩で読者に意味を発見させる
- 直接言い切りすぎない。余白を残して、読み手の中で言葉を完成させる
- 目指すトーンは「熟練したコピーライター」：エモさは使うが、押しつけない
