# X 共感投稿ストック（画像付き）10本

**用途**：毎回画像＋本文で「わかる」を取りにいくストック。  
**フェーズ**：非集客（売り込みなし・CTAなし）。  
**黄金比**：共感 4 ： 気づき 4 ： 思想 2（本セットは**共感寄り**）。

**画像の共通仕様**

| 項目 | 目安 |
|---|---|
| サイズ | **1200×675px**（16:9・X推奨）または **1080×1080px**（1:1） |
| ツール | Canva「X投稿」テンプレ |
| フォント | 明朝系（見出し）＋ゴシック（補足） |
| 色 | 背景は白・ベージュ・薄グレー。アクセントは**深緑 or 落ち着いた赤**（1色だけ） |
| 写真 | Unsplash等の**無人・日常**（窓辺・手帳・コーヒー・夕方の空）。顔出し不要 |
| 右下 | 小さく `ひとびじLAB` または `@hitobizi_lab` |

**使い方**：投稿前に「使用日」列へ日付を書く。画像内メインコピーと本文は**同じ芯、言い回しは変えてOK**。

## Canva 作業チェック（画像を作るとき）

1. テンプレ「Instagram 投稿」→ サイズを **1200×675** に変更（または X用テンプレ）
2. **メインコピーは20字前後×2行**まで。読み切れるサイズに
3. 写真は**コントラストを下げる**（文字が読めるように暗幕 or 白半透明）
4. 右下に `ひとびじLAB` を入れて統一感
5. PNGで書き出し → Xに添付 → 本文は画像の**言い換え**（同じ文をコピペしない）
