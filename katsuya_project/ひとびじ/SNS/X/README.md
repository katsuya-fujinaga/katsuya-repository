# X

ひとびじの X 運用に関するファイルをまとめるフォルダです。

## サブフォルダ

| パス | 内容 |
|------|------|
| **`戦略/`** | 非集客フェーズの方針、ブランディング、裏テーマ |
| **`投稿ストック/`** | ツイート文例、呟きストック、画像付き投稿案 |

## 運用メモ

- 投稿の正本は `投稿ストック/`
- 方針や解釈の正本は `戦略/`
- ブランド全体の運用設計は `../../../運用/` を参照する
